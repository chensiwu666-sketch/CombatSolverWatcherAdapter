## 详细描述（正文）

```
让《战斗路线求解器 / Combat Solver》看懂观者这个角色 mod。

观者不是原版角色，求解器默认无法推演她的卡，遇到会直接停下。本 mod 由两部分组成：
· 兼容层：把“遇到未适配内容就拒绝启动”降级为“尽力推演 + 明确标风险”
· 适配层：把观者的卡牌出牌效果、架势机制、部分能力的持续效果，按 mod 源码逐个镜像给求解器

────────────────────
【适用范围】请务必先读
────────────────────
这是一个**有限的适配层**，不是“完全兼容”。能精确推演的卡按 mod 源码实现来；
做不到的地方会在这条路线上打风险标记（红字），让你知道“这里求解器不确定”，而不是给你一个看起来正常、
其实算错的答案。

已做到：
· 卡牌出牌效果 79 / 83 张（观者牌池全量，逐条对照 mod 反编译源码写成）
· 架势机：平静 / 愤怒 / 神性 / 预见；含移除平静返 2 能量、进神性返 3 能量、紫莲花离开平静 +1 能量
· 伤害倍率：愤怒 ×2（含受到的伤害）、神性 ×3（仅造成的伤害）
· 能力持续效果 4 个：静水、沸腾之怒、神性形态、虔诚（含真言满 10 转神性）
· 隐藏状态进指纹：本场累计真言 / 本回合真言（光辉、福音的数值来源）
· 抽牌时点：无明（抽到即消耗，并按层数生成奇迹）

尚未做到（会在面板上标风险，或直接按“未适配”处理）：
· 多数能力牌的**每回合效果**没建模：打出这张牌是对的，但之后每回合的收益求解器看不到，
  因此它会低估这些牌的价值
· 研习、欧米茄的回合末效果未建模（求解器当前只开放回合末的晚阶段入口）
· Scry（看牌堆顶弃牌）：求解器没有这个机制，弃哪张由适配层按固定规则决定，不进入搜索分支，
  因此 scry 的价值会被低估
· 完全未适配 4 张：嘲讽、规劝（多人专属，单人局不出现）、他山之石（选项由游戏 RNG 现场抽取，
  无法与实机选牌页面对齐）、画符（效果是给牌附魔，求解器没有附魔概念）
· 观者的遗物未适配

────────────────────
【依赖】
────────────────────
· Slay the Spire 2 0.111.0
· Combat Solver ≥ 0.50.1（本版按 0.50.1 构建与验证）
· 观者（Watcher）≥ 0.10.8
· RitsuLib ≥ 0.6.0（Combat Solver 自身要求）

版本不匹配时适配层会**主动拒绝加载**并在日志里说明原因——宁可明确停摆，也不给出可信度不明的路线。

────────────────────
【安装】
────────────────────
1. 订阅并启用 Combat Solver 与观者
2. 把 WatcherAdapter.dll / .json 放进 <游戏目录>/mods/WatcherAdapter/
3. 把 CombatSolverCompat.dll / .json 放进 <游戏目录>/mods/CombatSolverCompat/
4. 启动游戏，在 mod 列表确认两项均已启用

若求解器给出的路线出现“未找到生还路线”或“计算失败”，请用求解器设置页的“导出问题包”发给我，
包里包含完整路线与逐检查点状态，能直接定位。

────────────────────
【致谢】
────────────────────
· Combat Solver：Torch（Torch1230/CombatSolver，MIT），其核心源自 hotwords123 的 Random Foreseer
  本适配层使用作者提供的第三方适配入口，不包含也不重新分发其任何代码或二进制
· 观者角色 mod：Boninall；本适配器与其作者无隶属关系
· 适配层代码：MIT
```
